## How to accept

**Opening a pull request against this repository constitutes acceptance of the
applicable agreement below**, for that contribution and every later one, unless
you state otherwise in the pull request description. We do not run a signing
bot; there is nothing to click.

If your employer requires a countersigned copy, or you would simply prefer an
explicit record, fill in the signature block at the end and email it to the
address in [`CONTRIBUTING.md`](CONTRIBUTING.md). Do not open a pull request
containing your signature — it would publish your contact details.

If you cannot agree to these terms, you can still file issues, review code, and
report security problems. Only code, docs, and other copyrightable
contributions require the CLA.
